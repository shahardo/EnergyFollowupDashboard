# Energy planning dashboard (Israel)

A Hebrew/RTL dashboard for planning Israel's energy system: demand by sector, supply by source, scenario
planning, channel priority, tracking, and **least-cost OSeMOSYS optimisation runs** in the background, on a model
generated from the dashboard's own data (exportable to [osemosys_israel](https://github.com/shahardo/osemosys_israel)).

All values are **sample data**.

This Space is deployed automatically from the GitHub repository; the source, documentation and setup steps
live there (`deploy/hf-space/SETUP.md`).
