# Energy Followup Dashboard

דאשבורד אינטראקטיבי לתכנון משק האנרגיה בישראל. הוא כולל שלושה מסכים:

1. **ביקוש:** עקומת ביקוש לפי מגזר, וסליידרים לשינוי קצב הצמיחה של כל מגזר.
2. **היצע:** בניית עקומת אספקה ממקורות שונים, כך שתכסה את כל הביקוש. הפער מוצג בגרף.
3. **מעקב ביצוע:** לוח גאנט שמראה את התקדמות הפרויקטים בכל ערוץ אספקה, מול היעדים.

האפליקציה סטטית ורצה בדפדפן, בלי שרת. תרחישים נשמרים כקבצי JSON מקומיים, דרך "שמור בשם" ו"פתח".

**סטטוס:** שלב התכנון. ראו את [מסמך האדריכלות](docs/ARCHITECTURE.md).
